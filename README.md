# DriveLab 智能驾驶工况仿真与辅助分析平台 V1.0

为智能驾驶工况前期评估提供五类轻量仿真、日志对标和可追溯分析。产品版本 V1.0，计算引擎 1.1.2。面向传智杯 AI WEB 网页开发挑战赛（10037）。真实免费模型与线上工作流已有实测，本轮工程软件复核修复低速适用性、日志尖峰、候选证据和报告时效问题。报名身份、指定评审访问和组委会接收须按真实后台确认。

## 功能

- 高速跟驰、弯道稳态、动态换道、紧急避障和城市路口；服务端校验参数并重算结果。
- 水平路面恒减速、稳态圆周、运动学单轨和五次换道需求；0.1 s 采样，末段不足 0.1 s 时精确止于用户时间窗。
- 停车距离、全过程间距预测、附着需求、侧向加速度、方向盘角、横摆角速度与估算制动压力；曲线、动画与 CSV 导出。
- CSV/JSON/TXT/TSV 日志清洗、单位换算、排序去重、时间对齐和共同区间插值；四通道 MAE、RMSE、最大绝对误差、平均偏差与覆盖范围。
- PDF/DOCX/TXT/Markdown 知识文件解析，页码/段落锚点与持久化分块索引；BM25 + 512 维词项向量检索。扫描 PDF 不做 OCR。
- 确定性规则分析；免费模型接入后可执行受限工具、依据计算证据与检索段落生成结构化解释。引用无效、请求失败或额度耗尽时明确降级，保留计算结果。
- 流式执行步骤、候选参数独立重算、证据 JSON、输入指纹；过期分析不作为当前记录保存。
- 账户隔离的 D1 记录和知识库；直接下载嵌入中文字体的 PDF，包含参数、图表、误差、来源和执行记录。
- 验证与证据页面：130 项独立解析参考、12 条固定检索回归、4,973 行 comma2k19 公开实测导入样例及来源许可。

## 本机启动

桌面“启动 DriveLab”会准备 PDF 解析资源、初始化/升级本地数据库并打开项目。开发工具和原始安装包保留在桌面“DriveLab 开发工具”，没有删除。

在其他电脑上：安装 Node.js 24 和 pnpm 11.25.0，克隆本仓库，在项目目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm run db:local
pnpm run dev
```

打开 http://127.0.0.1:5173/ 。本地保存需要通过页面登录；这是仅用于回环预览的模拟账号，线上使用 Sites 账户。`db:local` 支持重复执行，并兼容早期直接执行初始 SQL 的数据库，保留现有记录。状态存储在忽略的 `.wrangler/state`，不上传 GitHub。不要手动重复执行旧迁移 SQL。

## 免费模型

运行 `node scripts/model-setup.mjs`，打开 http://127.0.0.1:5174/ 。先由本人在魔搭完成阿里云账号绑定、实名认证及魔搭邮箱验证，再复制 **ms-** 开头的访问令牌到本机密码框。查询公开模型目录不等于鉴权通过，必须测试并保存。不要把令牌、验证码、身份证件发到聊天或 GitHub。

配置只存于忽略的 `.dev.vars`。免费保护默认开启：ModelScope 仅允许 API-Inference 免费入口及无提供方后缀的模型；OpenRouter 只允许免费模型。免费额度和可用模型以官方账户为准；不会自动切换付费。线上密钥只能设为 Sites 服务端 secret，且应在本地测试通过及获得云端授权后设置。

检索属于词项检索，**不是语义 embedding**。引用 ID 与 JSON 校验只能约束结构和来源，不保证模型文字完全正确。关键数字与风险等级由计算引擎给出，仍需要人工复核。

## 日志协议

```csv
time_s,speed_kmh,yaw_rate_dps,brake_pressure_bar,steering_angle_deg
0,100,0,0,0
0.1,100,0,0,0
0.2,100,0,0,0
```

时间列与至少一个测量通道必需。`timestamp_ms`、`speed_mps`、`yaw_rate_rad` 可自动换算，也可显式指定单位。先将首个有效时间归零，再添加偏移；正偏移使实测曲线向右移动。共同区间外不外推，缺失值不补零。方向盘角不是前轮转角；压力单位 bar。单次最多 5 MB / 20,000 行，通道绝对值不超过 1,000,000，超出时先检查单位。

MAE/RMSE/平均偏差保留共同区间内仿真网格等点权口径；最大误差及峰值时间使用仿真和采集两时间网格的并集，避免漏掉网格间采集尖峰。原始采样数量与插值网格数量分开；超过 1 秒采样间隙会提醒，插值不证明间隙中的真实变化。该提醒阈值是软件政策，不是传感器合格标准。

公开 comma2k19 样例不是受控工况；任意参数与其对比的差异不能作为模型精度或传感器故障证据。来源、固定提交、转换方法、哈希和 MIT 许可均随样例保留。

## 接口

| 接口 | 用途 |
| --- | --- |
| POST `/api/simulate` | 服务端参数校验与仿真 |
| GET `/api/status` | 数据库/模型配置状态，不返回密钥 |
| GET/POST `/api/records` | 当前账号的记录摘要/保存 |
| GET/DELETE `/api/records/:id` | 当前账号的完整快照/删除 |
| GET/POST `/api/knowledge` | 当前账号的资料/索引 |
| DELETE `/api/knowledge/:id` | 删除本人资料 |
| POST `/api/analyze` | 当前工况与日志分析，支持 SSE |

## 工程边界与协作

这是前期需求评估与学习工具，不是完整自动驾驶仿真或车辆安全认证系统。摩擦圆用于需求超限检查，不求解饱和后的真实运动。未包含感知规划、闭环控制、轮胎非线性、悬架、坡度与载荷转移；变速换道中的横摆/转向是近似需求。工程阈值、制动增益和车型适配需要车辆工程成员审核，尚无实车标定精度证据。

横向场景初始车速低于 5 km/h 时拒绝；该值是本软件适用范围，不是所有车辆的物理或法规限值。候选方案使用独立 CAND_n 事实范围，基线不被候选覆盖；PDF 导出复核当前输入指纹，附事实与候选登记。引用存在性不等同自然语言语义正确，关键结论仍需人工复核。
